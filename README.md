# DeepSeek Harness 桌面壳

一个轻量桌面客户端：不再需要手动在 cmd 里敲命令、再开浏览器访问，双击启动后自动完成一切。

**产品特性**

- **一键启动**：内置 cmd 终端（ConPTY）自动执行 `pnpm dlx @deepseek-ai/dsh@next web --no-open`（`@next` 拉取最新预发布版，`--no-open` 阻止新版 dsh 自动打开默认浏览器，页面只在壳内显示），启动画面实时显示终端输出（下载依赖、启动日志一目了然），就绪后主界面直接显示 Harness Web UI，无需打开浏览器；首次运行（系统无 dsh）自动显示「正在下载 DeepSeek Harness」，就绪超时放宽到 30 分钟；
- **下载代理**：默认使用系统代理设置（可改自定义代理），下载 dsh 自动走代理，网络受限环境也能顺利安装；
- **端口占用自动直连**：检测到服务已在运行（含上次退出未关闭的后台服务）时跳过启动、直接连接；
- **会话记忆**：工作目录自动跟随最后一次会话所在的 workspace；在客户端内打开过的会话，下次启动自动恢复；
- **内置终端**：右下角小按钮点击呼出/隐藏 cmd 终端，可看日志、手动输入；面板工具栏可直接**停止 / 重启**服务；
- **浏览器级缩放**（50%–300%）：终端面板按钮或 `Ctrl+=/-/0`，重启后保留；
- **绿色安装**：安装包可选「绿色安装」解压到自选目录，不建快捷方式、不写注册表；
- **干净退出**：关闭即清理服务进程不留残留；可选「退出后保持服务运行」，下次启动自动直连；保持运行模式下关闭时会询问是否同时结束后台服务（也可在终端面板「⏹」随时结束）。

## 系统要求

- Windows 10 / 11（自带 WebView2 运行时，无需额外安装）
- Node.js ≥ 20（含 npm）
- **pnpm**（dsh 由 pnpm 拉取运行）：`npm i -g pnpm` 一键安装

> **pnpm 10+ 构建脚本说明**：pnpm 默认禁止依赖包执行安装构建脚本（postinstall），dsh 的原生依赖需要。执行一次
> `pnpm config set dangerouslyAllowAllBuilds true` 即可全部放行（推荐在安装 pnpm 后设置）。

## 从 0 开始

1. 安装 Node.js ≥ 20 与 pnpm：`npm i -g pnpm`；
2. 获取安装包 `dsh_shell_0.1.24_x64-setup.exe`；
3. 双击运行，选择安装方式：
   - **标准安装**：装到用户目录，创建开始菜单/桌面快捷方式，可在「设置 → 应用」中卸载；
   - **绿色安装**：自选目录，仅解压文件，不建快捷方式、不写注册表，不检测/不干预运行中的程序，删除目录即卸载。
4. 安装完成后双击「DeepSeek Harness」启动即可（首次启动会自动下载 dsh 软件包，需联网，稍候片刻）。

命令行静默安装（可选）：`setup.exe /S /G /D=D:\tools\dsh-ui`（`/S` 静默，`/G` 绿色模式，`/D` 指定目录且必须放最后）。

## 基本操作

| 操作 | 说明 |
|---|---|
| 启动 | 自动在终端中执行启动命令（默认 `pnpm dlx @deepseek-ai/dsh@next web --no-open`），就绪后主界面加载 `http://127.0.0.1:3080/`；`--no-open` 让新版 dsh 不自动打开系统浏览器（页面只在壳内显示），如确需在浏览器打开可去掉该参数 |
| 端口占用 | 检测到端口已有服务时跳过启动、直接连接（终端会显示提示） |
| 终端按钮 | 右下角小按钮（绿点=运行中，红点=已停止/失败）：点击呼出/隐藏终端；终端内可看日志、手动输入命令、`Ctrl+C` 停止服务 |
| 启动画面输入 | **启动等待期间，画面上的终端也可直接输入**（点击画面中的终端区域聚焦即可）——首次运行遇到交互确认（如安装询问 y/N）可直接在画面上应答，不必展开面板 |
| 会话恢复 | 在客户端内打开过的会话会自动记住，下次启动直接恢复；工作目录自动跟随最后会话的 workspace |
| 缩放 | 终端面板上的 −/％/＋ 按钮，或 `Ctrl+=` / `Ctrl+-` / `Ctrl+0` 重置 |
| 设置 | 终端面板右上「⚙」：修改启动命令、工作目录、端口、就绪超时、退出保持服务等 |
| 停止/重启服务 | 终端面板「⏹」停止服务（含后台 keep-alive 服务，无需任务管理器）、「⟳」重新启动；服务异常后按钮变红，点击展开再重启 |
| 导出下载 | 会话日志导出（如 `dsh-session-*.zip`）自动保存到系统「下载」目录，终端面板会记录下载日志 |
| 退出 | 关闭主窗口即退出并清理服务进程；若开启「退出后保持服务运行」，关闭时会询问「保持运行 / 结束服务」，服务留在后台则下次启动自动直连 |

## 文件路径

| 路径 | 说明 |
|---|---|
| `%LOCALAPPDATA%\DeepSeek Harness\` | 标准安装目录（绿色安装为你自选的目录） |
| `%APPDATA%\com.dsh-ui.app\settings.json` | 客户端配置文件（**标准安装**） |
| `%APPDATA%\com.dsh-ui.app\logs\dsh-service.log` | 退出后保持运行时，后台服务的输出日志（标准安装） |
| `%USERPROFILE%\.dsh\` | DeepSeek Harness 数据目录（profiles / sessions 等） |

> **绿色安装**：程序目录内含 `portable.marker`，配置（`settings.json`）与后台服务日志
> 直接存放在**程序同目录**，整个文件夹可移动/复制，配置随目录走。

> 工作目录默认**自动跟随最后一次会话所在的 workspace**（`~/.dsh/sessions` 下最新会话），
> 打开应用后会话列表即显示你之前的会话；如需固定目录，在设置中手动指定即可。

## 配置文件说明

配置文件为 `%APPDATA%\com.dsh-ui.app\settings.json`（**绿色安装**时在程序目录的 `settings.json`），也可在浮层「⚙」中修改（界面优先）：

| 项 | 默认 | 说明 |
|---|---|---|
| `startup_command` | `pnpm dlx @deepseek-ai/dsh@next web --no-open` | 自动执行的启动命令（`@next` = 最新预发布版；pnpm dlx 自动下载运行；`--no-open` 阻止新版 dsh 自动打开系统浏览器） |
| `working_dir` | 自动跟随 | 留空时自动跟随最后会话的 workspace；手动设置后以手动值为准 |
| `port` | 3080 | 探测与导航端口 |
| `ready_timeout_sec` | 120 | 就绪等待超时（首次拉取依赖可能较久） |
| `zoom` | 1.0 | 缩放因子（0.5–3.0） |
| `auto_start` | true | 启动时自动运行服务 |
| `keep_alive_on_exit` | false | 退出客户端后保持服务后台运行 |
| `auto_restart` | false | 服务异常退出后自动重启（最多 3 次） |
| `use_system_proxy` | true | 下载 dsh 时使用系统代理（WinINET 设置）；**修改后重启服务生效** |
| `proxy_url` | 空 | 自定义代理地址（如 `http://127.0.0.1:10808`），关闭「使用系统代理」后生效；**修改后重启服务生效** |
